# 项目：群体行为模拟器

## 1. 核心目标

开发一个桌面应用程序，在指定大小的2D窗口中模拟群体行为（如鸟群、鱼群）。

## 2. 技术约束与要求

- **性能目标**：在普通集成显卡上，流畅模拟 **1000个** 以上的个体，帧率不低于 **30 FPS**。
- **个体渲染**：所有个体均使用 **固定形状图像**（如圆形、三角形），不涉及骨骼动画或复杂纹理，以降低GPU开销\[citation:7]。
- **交互方式**：用户可以在窗口中 **添加/移除** 个体，或通过鼠标点击设置目标点，群体需能响应此目标点（如聚集或跟随）。
- **核心算法**：实现经典的 **Reynolds群体规则**（分离、对齐、聚集）\[citation:1]，并使用 **空间哈希网格（Spatial Hashing）** 优化邻居搜索，避免O(n²)的复杂度\[citation:3]。

## 3. 推荐架构方案

- **主语言**：C++（用于核心模拟逻辑）。
- **界面与渲染**：使用 **SDL2** 或 **Qt + OpenGL**，利用硬件加速的 `glDrawArraysInstanced` 等API进行实例化渲染。
- **数据结构**：个体位置、速度等属性存储在连续内存数组（`std::vector` 或 `std::array`）中，以提升缓存命中率。

## 4. 期望输出

- 一个可运行的桌面程序。
- 包含清晰的模块划分：`Simulation`（逻辑）、`Renderer`（渲染）、`UI`（用户交互）。
